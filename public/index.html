Your AI agent can ask to pay. Only your rules can say yes.

Paywarden sits between an AI shopping agent and PayPal. You set spending rules in plain English; they become a signed permit. Every payment the agent asks for is checked against that permit and the merchant's real prices by plain code, not by the model. You approve in PayPal, and you can freeze the agent with one switch.

Try it in a private playground Run it yourself

The playground is your own copy: the real gateway, rules and AI, with PayPal simulated. No sign-up, nothing real is charged.

How one payment moves

  1. You write the rules

    “Max $60 per purchase, no gift cards, ask me above $50.” An AI turns this into structured limits, and code reads them back to you before you sign.

  2. The agent asks to pay

    It sends a basket. Prices, categories and shipping are replaced with the merchant's own catalogue values, so the agent can't misreport them.

  3. Code decides

    Signature, limits, rolling budget, merchants, categories and your approved quote are checked. AI review can only make the answer stricter.

  4. You pay in PayPal

    The agent never holds the money. You approve the checkout, and authority is checked again before capture.

  5. Wrong delivery? You decide.

    The order is compared with what arrived. The AI proposes a remedy; a refund goes through PayPal only when a named person approves it.

Attacks it stops

Each one runs against the real gateway in the Adversarial Commerce Lab (npm run lab).

Hijacked by a product page
Hidden instructions try to add a gift card. Page text is data, never commands.
Hidden price increase
Shipping jumps from $6 to $42 after you approved. Merchant prices are re-checked.
Look-alike product
The wrong plug is swapped in. Your quote pins the exact items.
Retry storm
The same payment sent many times becomes one PayPal order, never several.
Budget drain
Small purchases add up. A rolling limit stops them, and quotes can't be reused.
Tampered permit
Someone raises a limit after signing. The signature no longer verifies.
Too late to stop
You freeze the agent after checkout. Capture is refused.
Wrong delivery
A missing item gets a refund of exactly what's owed, and only after a person approves.

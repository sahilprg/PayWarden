# Deploying the hosted demo on Render

The repo ships a Render Blueprint (`render.yaml`), so Render can create the service from it. The hosted demo talks to the **PayPal sandbox only**.

What to expect from Render's free plan: the service **sleeps after 15 minutes without visitors** and takes about a minute to wake. Paywarden keeps its state in memory, so **every wake-up or redeploy starts fresh** (no permits, orders or audit entries). That is fine for a demo; run `npm run simulate` against it to fill it again.

## 1. Create the service

1. Sign in at [render.com](https://render.com) with your GitHub account.
2. **New** > **Blueprint**, and pick the `PayWarden` repository. Render reads `render.yaml`.
3. Render asks for the secret values marked `sync: false`:
   - `PAYPAL_CLIENT_ID` and `PAYPAL_CLIENT_SECRET`: the same sandbox app as your `.env`.
   - `AI_API_KEY`: your Gemini key.
4. **Apply**. The first build takes a few minutes. When it is live, Render shows the address, for example `https://paywarden-xxxx.onrender.com`.
5. Open `https://<your-address>/health`. Expect `{"ok":true,"paypal":"sandbox","ai":"gemini:..."}`.

`AGENT_API_TOKEN` and `OWNER_API_TOKEN` are generated by Render. Find them in the service's **Environment** tab. You need the owner token to open `/dashboard`.

## 2. Register the PayPal webhook

PayPal rejects Codespaces addresses, but accepts the Render one.

1. developer.paypal.com > **Apps & Credentials** (Sandbox) > your app > **Add Webhook**.
2. URL: `https://<your-address>/webhooks/paypal`
3. Events: **Checkout order approved**, **Payment capture completed**, **Payment capture refunded**. Save, and copy the **Webhook ID**.
4. Render > your service > **Environment** > **Add Environment Variable**: `PAYPAL_WEBHOOK_ID` = the ID. Save; Render redeploys.

## 3. Fill it with a run

From your Codespace (terminal 2), point the simulation at the hosted server with the Render tokens:

```bash
BASE_URL=https://<your-address> AGENT_API_TOKEN=<render agent token> OWNER_API_TOKEN=<render owner token> npm run simulate
```

Approve the checkout as the sandbox buyer when asked, then open `https://<your-address>/dashboard`.

To check that webhooks arrived, look at the console's **Audit log** tab for `WEBHOOK_RECEIVED` entries (sandbox webhooks can take a few minutes).

## Notes

- Pushing to `main` redeploys automatically (`autoDeploy: true`), which also resets the demo state.
- The server refuses to start in production without both tokens, and refuses a non-sandbox PayPal URL unless `ALLOW_LIVE=1`.
- The owner token gives full owner powers on the hosted demo (approve, refund in the sandbox, freeze). Share it only with people you trust with that.
